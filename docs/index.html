左下の丸いスティックで移動。ドラッグで視点を回転、2本指でズーム。

女の子を選び「一緒にリズム遊び」。相手のポーズに合わせて青いゾーンでタップすると特典GET。

「声をかける」から会話を始め、相手の手に勝つ手をタップ。5回中3勝できたらホテルかネットカフェに誘い、入口まで一緒に歩こう。断られたら次の出会いを探そう。

同行中は相手の近くで歩こう。合図が出たら5秒以内に右下ボタンで応えるとコンボとスコアUP。ゴール後は記念写真を保存できます。
